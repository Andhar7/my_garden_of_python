  📚 PART 1: Why Your Question Matters

  In your Challenge 2 analysis, you found:

  - ❌ Performance doesn't predict salary
  - ❌ Money doesn't make people happy

  Two possibilities:

  Possibility A: DATA IS WRONG ❌

  Possibility B: DATA IS REAL ✅

  - → Analysis reveals TRUE INSIGHTS

  ---
  🔍 PART 2: How to Test if Data is Good

  Test 1: Data Completeness

  # Check if any values are missing
  print(employee_data.isnull().sum())

  # If missing many values → Data quality problem ❌

  Test 2: Data Range Check

  # Check if values make sense
  print(employee_data['Salary'].min())      # Should be > 0
  print(employee_data['Salary'].max())      # Should be realistic
  print(employee_data['Performance_Score']) # Should be 50-100

  # If values are weird → Data quality problem ❌

  Test 3: Data Distribution

  # Check if distribution makes sense
  sns.histplot(data=employee_data, x='Salary')

  # Should look like real salary distribution
  # If flat/strange → Data quality problem ❌

  Test 4: Logical Consistency

  # Check for impossible combinations
  # Example: Employee with 30 years experience but hired last month?

  # If many illogical combinations → Data quality problem ❌

  Test 5: Data Source Audit

  Questions to ask:
  - Who collected this data? (HR system? Manual entry?)
  - When was it collected? (Current? Old?)
  - How was it collected? (Automated? Manual?)
  - Is it complete? (All employees? Some sample?)
  - Is it honest? (Real values? Estimated? Faked?)

  If answers are unclear → Data quality problem ❌

  ---
  📊 PART 3: Company Strategy for "Sincere Data"

  What's "Sincere Data"?

  Data that:
  - ✅ Reflects REALITY
  - ✅ Is collected HONESTLY
  - ✅ Is measured ACCURATELY
  - ✅ Has NO BIAS
  - ✅ Is COMPLETE

  Company Strategy to Get Sincere Data:

  Step 1: Automated Systems
  ❌ BAD: Manager manually writes salaries
  ✅ GOOD: HR system automatically records from payroll

  Step 2: Anonymous Surveys
  ❌ BAD: "Tell us if you're satisfied" (name required)
         → People lie to please boss
  ✅ GOOD: Anonymous survey
         → People answer honestly

  Step 3: Regular Audits
  ❌ BAD: Use old data from 2 years ago
  ✅ GOOD: Audit data monthly/quarterly
         → Catch errors early

  Step 4: Multiple Sources
  ❌ BAD: Only manager's opinion on performance
  ✅ GOOD: Performance = 360 reviews + metrics + manager
         → More reliable picture

  Step 5: Clear Definitions
  ❌ BAD: "Satisfaction" means different things to everyone
  ✅ GOOD: Define clearly:
         "Satisfaction = score 1-10 on 5 specific questions"
         → Everyone understands same way
